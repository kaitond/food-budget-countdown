# 食費カウントダウン

月の食費予算を日割りして、**今週あと使える額**をカウントダウン表示する家計簿アプリ。

- 依存ライブラリ・ビルド不要（`index.html` 1枚で完結）
- データは端末のブラウザ内（localStorage）に保存。サーバーには一切送信しません
- PWA対応：ホーム画面に追加すればアプリとして起動、オフラインでも動作

## 使い方

1. ⚙ から**月の食費予算**を設定
2. 買い物のたびに金額とカテゴリを入力（レシート写真の添付も可）
3. 中央の大きな数字が「今週あと使える額」

## 計算方法

```
1日あたり = 月予算 ÷ その月の日数
週予算   = 1日あたり × その週の日数
今週の残り = 週予算 (+ 繰越) − 今週使った額
```

週予算の合計は必ず月予算に一致します。月末の半端な週も自動で調整されます。

## 設定

| 項目 | 内容 |
| --- | --- |
| 月の食費予算 | 1か月に使う食費の上限 |
| 週の区切り | 1日から7日ごと / 月曜はじまり / 日曜はじまり |
| 繰越 | 先週の余りを今週に足す（同じ月の中でのみ） |
| データ | JSON で書き出し・読み込み・全消去 |

端末をまたいだ同期はありません。機種変更や別端末への移行は、書き出したJSONを読み込んでください。
