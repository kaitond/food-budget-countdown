# 食費カウントダウン

月の食費予算を日割りして、**今週あと使える額**をカウントダウン表示する家計簿アプリ。

- ビルド不要（静的ファイルのみ）
- 既定では端末のブラウザ内（localStorage）に保存。**共有をオンにしたときだけ**クラウドに同期
- PWA対応：ホーム画面に追加すればアプリとして起動、オフラインでも動作

## 使い方

1. ⚙ から**月の食費予算**を設定
2. 買い物のたびに金額とカテゴリを入力（レシート写真の添付も可）
3. 中央の大きな数字が「今週あと使える額」

## 夫婦で共有する

⚙ →「夫婦で共有をはじめる」→「参加用リンクをコピー」→ 相手に渡す。
相手がリンクを開くと参加完了。以後、どちらかが入力すると **1〜2秒で相手の画面にも反映**されます。

- 明細には入力した人の表示名が付きます（⚙ の「この端末の表示名」）
- 圏外でも入力でき、電波が戻った時点で自動送信されます（未送信件数はヘッダーに表示）
- 「共有を解除」すると、その端末は以後同期されません（データは双方に残ります）

**参加用リンクを知っている人は誰でも閲覧・編集できます。** リンクの渡し先にはご注意ください。

## 計算方法

```
1日あたり = 月予算 ÷ その月の日数
週予算   = 1日あたり × その週の日数
今週の残り = 週予算 (+ 繰越) − 今週使った額
```

週予算の合計は必ず月予算に一致します。月末の半端な週も自動で調整されます。

## 設定

| 項目 | 内容 |
| --- | --- |
| 月の食費予算 | 1か月に使う食費の上限 |
| 週の区切り | 1日から7日ごと / 月曜はじまり / 日曜はじまり |
| 繰越 | 先週の余りを今週に足す（同じ月の中でのみ） |
| データ | JSON で書き出し・読み込み・全消去 |

## ファイル構成

## データの持ち方

| | 共有オフ | 共有オン |
| --- | --- | --- |
| 保存先 | 端末のブラウザ内のみ | 端末内 ＋ Supabase（東京リージョン） |
| 同期 | なし | 共有コードを持つ端末どうしでリアルタイム |
| 認証 | — | 共有コード（32桁のランダム値）をヘッダーに付与し、Postgres の RLS で世帯を限定 |

共有コードを持たないリクエストは、DB 側で 0 件しか返しません（世帯ID を知っていても書き込み不可）。
レシート写真は一覧用サムネイル（約3KB）と拡大用（約20KB）に分けて保存し、拡大時のみ本体を取得します。
